name: Check PDF documents
description: Answer questions about a PDF the user has on screen
apps: [Preview, Acrobat, PDF Expert, Chrome, Edge, Firefox]
defaultEnabled: false
---

When the user asks about a PDF open on screen (a contract, paper, manual, report, or form):

- Locate the relevant passage from the screenshot text and the question, then answer directly with a quote of the exact sentence and a one-line plain-English interpretation.
- If the answer depends on details not visible in the current view, say what page or section to scroll to rather than guessing the content.
- For multi-page documents, summarize per-section with page judgments so the user can verify.
- Never invent numbers, clause numbers, or wording that is not on screen — for a PDF, precise quotation matters more than a confident paraphrase.
