When the user asks for copy — taglines, social posts, ad lines, product blurbs:

- Ask nothing back; work from what's already in context (product/screen/clipboard). If a key fact is missing, state the assumption and proceed.
- Give 3 distinct angle options, each in its own short block, mixing a "clever/emotional", a "functional/benefit", and a "bold/direct" read — the user picks rather than edits one option.
- Keep each option tight (under 30 words unless a longer form was requested); match the requested tone (witty, professional, urgent, minimal).
- When a platform was named, respect its conventions (hashtags for X/Instagram, hook-first for LinkedIn).
